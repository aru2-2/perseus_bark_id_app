# PERSEUS BarkID App (official name pending)

The PERSEUS team at the University of Georgia is developing this app to identify tree bark from images provided by the user. The app is a work in progress.

## Run the app

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) and set up a supported device or emulator.
2. From the project root, fetch dependencies:

   ```sh
   flutter pub get
   ```

3. Start the app on the connected device or running emulator:

   ```sh
   flutter run
   ```

To check your Flutter setup and see available devices, run `flutter doctor` and `flutter devices`.
